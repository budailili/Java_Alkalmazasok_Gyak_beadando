Végpontok

Alap URL: /api/jarmuvek

MetódusÚtvonalLeírásVálasz
GET/api/jarmuvek Az összes jármű listája200
GET/api/jarmuvek/{rendszám} Egy jármű adatai200, 404
POST/api/jarmuvek Új jármű felvétele (JSON törzs)201, 400, 409
PUT/api/jarmuvek/{rendszám} Márka és szín módosítása200, 400, 404
DELETE/api/jarmuvek/{rendszám} Jármű törlése (ha nem tartozik hozzá személy)204, 404, 409

Példa JSON törzs

{
  "rndszm": "KLM901",
  "marka": "Opel",
  "szin": "fekete"
}

cURL példák

curl -i http://rivendell.nje.hu:9443/gvlrpx/api/jarmuvek

curl -i -X POST -H "Content-Type: application/json" \
  -d "{\"rndszm\":\"KLM901\",\"marka\":\"Opel\",\"szin\":\"fekete\"}" \
  http://rivendell.nje.hu:9443/gvlrpx/api/jarmuvek

curl -i -X PUT -H "Content-Type: application/json" \
  -d "{\"marka\":\"Opel\",\"szin\":\"ezüst\"}" \
  http://rivendell.nje.hu:9443/gvlrpx/api/jarmuvek/KLM901

curl -i -X DELETE http://rivendell.nje.hu:9443/gvlrpx/api/jarmuvek/KLM901
